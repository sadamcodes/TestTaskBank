# Тестовое задание для собеседование по языку C#"

## Описание
Система для отслеживания прихода и ухода сотрудников на завод.

## Функционал
- CRUD для сотрудников
- Учет смен
- Список должностей
- Статистика нарушений (бонус)

## Стек
- .NET 8
- ASP.NET Core Web API
- Entity Framework Core
- PostgreSQL

## Как запустить
1. Клонировать репозиторий
2. Настроить строку подключения в appsettings.json
3. Выполнить Update-Database
4. Запустить проект
